# v0.3.0 — MVP 离线演示与最终验收版本

发布日期：2026-10-04。本版本用于可信本地环境的产品演示，不是生产部署版本。

## 本次交付

- 青铜鼎、青花瓷瓶、陶俑三个离线 Demo 样本，明确标注演示用途；本地 Mock 模型、来源资料和图片，不依赖真实 AI API。
- 完整知识卡、四种讲解、人工编辑与审核、发布、游客展示闭环，来源、版本和处理记录可追溯。
- 中文首页、Dashboard、统一博物馆风格、状态与错误反馈、移动端排版。
- AI 故障、上传、数据库、重复操作与公开访问保护的稳定性验证。
- 新增隔离 MVP 验收脚本及最终报告，更新架构、使用说明、产品概览与后续规划。

## 验收结论

lint、typecheck、build、AI 单测、MVP、Demo 与稳定性套件通过。无密钥、DEMO_MODE 和 AI 断连时专用 Demo 通过。浏览器实测现有标准闭环约 71 秒，无明显白屏和控制台报错。

严格需求清单仍有两项未完成：新流程的馆藏资料文件上传、授权确认与校验。现有粘贴来源文字不等于文件上传。Mock 不实际识图；没有登录与馆别权限，不可直接部署公网。

## 下载与启动

下载仓库根目录的 `MuseumAI-Studio-v0.3.0-source.zip`，解压后按 README 安装前端依赖、配置环境并执行迁移。无需 Docker，新流程不需要 Python 后端。不要覆盖已有 .env 或工作数据库。

ZIP 由提交的源码生成，不含密钥、数据库、用户上传、依赖、构建产物和旧版 ZIP。首次安装需网络，完成准备后 `/demo` 可离线运行。
