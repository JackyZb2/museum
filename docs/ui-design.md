# 界面与演示体验说明

本阶段仅优化界面、可读性和反馈，保留现有数据库、AI Provider、审核与发布规则。

## 页面入口

- `/`：项目首页，展示产品定位、三项能力以及工作台和演示入口。
- `/dashboard`：工作台概览，读取现有文物、待审核、已发布及来源资料统计。
- `/assets`：文物知识卡列表。
- `/assets/new`：分组填写基本信息、图片及来源资料。
- `/assets/[id]`：知识卡、分析进度、讲解与处理记录。
- `/assets/[id]/review`：四种讲解的编辑、来源依据和人工审核。
- `/demo`：离线演示，保留人工确认后再发布的流程。
- `/exhibit/[id]`：游客展示，仅显示已发布文物及已审核讲解。

## 视觉规范

采用暖白背景、深绿操作色和青铜色点缀。标题使用本地中文衬线字体，正文使用本地系统中文字体，不依赖在线字体。避免大量渐变、复杂动画和游戏化设计。

状态徽章同时包含文字与颜色。错误、成功、提示反馈使用统一组件。进度条展示实际步骤，不给出虚构的完成时间。空页面提供下一步入口，加载页面使用静态骨架。

## 导航与阅读

后台使用统一导航和面包屑，手机端导航自动换行。游客页不出现后台操作入口。讲解正文限制阅读宽度，保留清晰行距。游客讲解标签支持方向键、Home 和 End 键切换。

## 验证与边界

已检查桌面首页、工作台、文物列表，以及手机尺寸下的新增文物、演示和游客页面；已验证游客讲解标签的键盘切换。浏览器检查使用隔离测试数据库，不修改工作人员现有馆藏。

加载边界只放在工作台和文物后台路由，不在全局添加加载边界，以免游客页提前发送成功响应而破坏未发布文物的 404 保护。

本阶段不新增 PDF 解析、音频播放、AI 模型或数据库业务字段。
